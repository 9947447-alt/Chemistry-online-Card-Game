本文档用于记录 MVP 0 已明确采用、暂缓或特别裁定的规则。两份原始规则文档保持不变；本文只说明 MVP 0 的实现口径，不改写原始规则。

- `docs/rules/core-rules-v0.1.docx`：核心游戏流程、开局、实验周期、行动、伤害、状态、淘汰、胜负与响应基础规则。
- `docs/rules/ion-reaction-and-diy-manual-v1.0.docx`：离子用途、反应关系、DIY 构建、气体与化学效果含义。

## 二、MVP 0 已裁定规则

### 基础范围

- MVP 0 只支持本地双人、公开调试模式。
- MVP 0 不实现角色、角色体力差异、角色摸牌规则和角色技能。
- 双方初始体力均为 10。
- 每个实验周期 3 个实验轮次。
- 每名玩家每周期最多 1 次主动 DIY。
- 响应 DIY 在 MVP 0 中关闭。

### 状态与响应

- `SO2_LEAK` 与 `FIRE` 是持续负面状态。
- 同名状态不叠加；已有同名状态时再次获得，只记录状态刷新日志。
- 不同状态可以同时存在，并按获得时间从早到晚处理。
- `SO2` 在 MVP 0 中只施加 `SO2_LEAK`，不造成即时伤害。
- `SO2` 与“实验台起火”施加状态时，不开启即时响应窗口。
- 目标只能在自己下一次行动开始时的状态处理窗口中处理 `SO2_LEAK` 或 `FIRE`。
- `SO2_LEAK` 与 `FIRE` 在 MVP 0 中标记为“阻止回复”的负面状态。

### CO2

- 酸与碳酸盐响应生成的 CO2 在 MVP 0 中只写入操作日志。
- 该 CO2 不创建 `CardInstance`，不创建 token，也不能作为后续可用资源。
- 手牌中的 `CO2` 物质牌仅用于 `FIRE` 状态处理窗口。
- 主动 DIY `C + O + O -> CO2` 不创建 CO2 卡牌；仅当行动玩家当前拥有 `FIRE` 时可用，并立即移除自己的 `FIRE`。

### O2 自我回复

- `O2` 是可从牌库摸到的物质牌，不是通过 `O + O` 临时生成。
- 仅存活的 `activePlayer` 可在 `mainAction` 使用。
- `O2` 仅能对自己使用。
- 使用时弃置 1 张手牌中的 `O2`，回复 2 HP，且不超过自己的 `maxHp`。
- 使用 `O2` 不进入 `responseWindow`。
- 满 HP 时不能使用 `O2`。
- 当自己拥有 `SO2_LEAK` 或 `FIRE` 时不能使用 `O2`。
- `H2O` 仅用于处理 `FIRE`，不回复 HP。
- `O + O -> O2` 主动 DIY 仍暂缓。

## 四、规则冻结表

| 原始规则 | MVP 0 是否采用 | MVP 0 替代规则 | 原因 | 引擎状态 |
| --- | --- | --- | --- | --- |
| 2-6 人，角色牌决定体力与摸牌 | 部分采用 | 只做本地双人；无角色；双方 10 HP | 缩小 MVP 范围，先验证核心闭环 | 已实现 |
| 每周期 3 个实验轮次，周期结束弃置手牌 | 采用 | 保持原规则 | 核心节奏稳定 | 已实现 |
| 主牌堆不足时弃牌堆洗回 | 采用 | 保持原规则；正在手牌中的牌不洗回 | 保持卡牌区域完整性 | 已实现 |
| 默认自由出牌 | 部分采用 | 允许自由选择主行动牌，但禁止无即时合法效果出牌 | 避免空打一张元素/离子造成程序与体验歧义 | 已实现 |
| 酸/碱基础伤害与中和 | 采用 | 稀酸/稀碱造成 1 点 acid/base damage，可被相反酸碱响应 | MVP 0 核心攻防 | 已实现 |
| 酸与碳酸盐生成 CO2 | 部分采用 | 只写日志，不创建资源或卡牌 | 暂不引入临时资源系统 | 已实现 Na2CO3；CO3^2- 待裁定 |
| SO2 有害气体可能造成即时伤害 | 不采用 | 只施加 `SO2_LEAK` 状态 | MVP 0 用状态窗口统一处理有害气体 | 已实现 |
| 火情状态 | 采用并细化 | `FIRE` 持续存在；未处理时行动开始受到 2 点状态伤害 | 明确持续性和处理窗口 | 已实现 |
