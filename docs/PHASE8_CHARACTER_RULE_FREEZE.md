# Phase 8 角色系统规则冻结

本文档是 Phase 8 角色系统的正式冻结规则。它只显式解冻 `docs/MVP0_RULE_FREEZE.md` 中“暂不实现角色、角色体力差异、角色摸牌规则和角色技能”的限制；除本文件明确覆盖的角色相关条款外，MVP 0 的其他冻结规则继续有效。

特别是，7C 关联出牌、68 张普通实体卡池、`tableReference`、主动 DIY、`FIRE` / `SO2_LEAK` 与 `statusWindow`、响应 DIY 关闭等既有规则不得被本阶段隐式改写。`docs/MVP_PLAN.md` 仅记录开发拆分，不得覆盖本文件的冻结规则。

## 一、角色通则

- Phase 8 共冻结 7 个角色。
- 每名玩家挂载 1 个角色。
- 角色牌不进入主牌堆，不创建普通 `CardInstance`。
- 角色技能默认不更新 `tableReference`。
- 角色技能默认不改变 `usedDIYThisCycle`。
- 主动技能只能在行动开始状态处理完成后、正常行动前发动。
- 占用行动的主动技能发动后，本行动不能再普通出牌、执行实体牌效果、主动 DIY，或发动另一个占用行动的主动技能。
- 被动技能不占行动。
- 响应技能只在技能明确指定的窗口发动。
- “失去体力”不是 `DAMAGE`，不触发普通响应、防御、免疫、增减伤或伤害上限。
- 角色的每周期次数在新实验周期开始时重置。
- 角色的每实验轮次次数在新实验轮次开始时重置。
- 角色技能不得重新引入 `event_lab_fire` 普通实体牌。
- 角色系统不得改变普通实体卡池 68 张的冻结数量。

## 二、回复规则

- 玩家存在 `FIRE` 或 `SO2_LEAK` 时，不能通过普通卡牌或角色技能回复体力，除非未来效果明确写出例外。
- 回复技能发动前必须先检查玩家能否回复。
- 若完全不能回复，对应回复选项或主动技能不可发动：不弃牌、不消耗技能次数、不占用行动，也不产生其他副作用。
- 回复不得超过 `maxHp`。

## 三、持续手牌上限

- 化工厂 CEO 的手牌上限 14 在所有时点生效，不只作用于周期开始摸牌。
- 任何摸牌效果达到 14 张后立即停止继续摸牌。
- 不设计“超过后弃牌”；正常结算不得使 CEO 手牌超过 14。
- 其他角色暂不设置持续手牌上限；其周期开始摸牌数量仍按各自角色规则执行。

## 四、强酸、强碱与虚拟 DIY 边界

- 强酸、强碱角色加成只读取实体 `CardDefinition` 上正式冻结的游戏标签。
- 不根据现实化学知识、化学式相似或离子来源临时推断标签。
- 主动 DIY 构建的稀 HCl、稀 H2SO4、稀 NaOH、稀 KOH、稀 Ca(OH)2 不自动获得角色所需的“实体强酸”或“实体强碱”加成。
- DIY 继续按自己的虚拟效果与稀溶液伤害规则结算。
- 本轮不新增或修改卡牌标签；正式标签映射是 Phase 8C 实现前的独立数据校准任务。

## 五、普通 DAMAGE 修饰顺序

普通 `DAMAGE` 按以下固定顺序结算：

1. 确定基础伤害。
2. 应用攻击方“伤害视为 X”等设定值效果。
3. 应用攻击方加法增伤。
4. 检查防御方免疫；若免疫成立，最终伤害直接为 0，并跳过最低伤害规则。
5. 应用防御方减伤。
6. 应用技能明确写出的最低伤害值。
7. 应用普通单次伤害最高 3 点上限。
8. 扣除 HP，检查淘汰与 `gameOver`。

补充边界：

- “免疫”优先于“最低为 1”。
- 没有最低值文字时，减伤可以使伤害降为 0。
- 普通伤害不得低于 0。
- “失去体力”完全绕过上述 `DAMAGE` 修饰顺序。
- Phase 8A 不实现通用伤害修饰层；该工作属于 Phase 8C。

## 六、角色冻结规则

### 1. 实验室老师

- `maxHp`：10。

#### 备课

- 周期开始触发。
- 摸 20 张，选择 10 张作为手牌，其余弃置。
- 不占行动。
- 必须使用安全、显式的选牌阶段，不能由 UI 直接修改状态。
- 若牌堆不足，沿用现有牌堆重洗规则。

#### 补课

- 主动技能，每周期一次。
- 手牌不超过 4 张时才能发动。
- 摸 4 张。
- 占用本行动。
- 不更新 `tableReference`。
- 不改变 `usedDIYThisCycle`。

### 2. 化工厂 CEO

- `maxHp`：10。

#### 资金储备

- 周期开始摸 14 张。
- 手牌上限始终为 14。
- 不需要选牌阶段。

#### 紧急调货

- 主动技能，每周期一次。
- 手牌不超过 4 张时才能发动。
- 摸 3 张，但不能超过 14 张上限。
- 占用本行动。
- 不更新 `tableReference`。
- 不改变 `usedDIYThisCycle`。

### 3. 手残党党委书记

- `maxHp`：10。
- 每周期最多发动以下三个主动技能中的任意一个，三个技能共享同一个每周期次数。

#### 尾气泄漏

- 所有其他存活玩家分别受到即时 2 点 SO2 `DAMAGE`。
- 每名目标可使用合法碱性吸收响应，多目标分别结算。
- 若所有合法目标最终都完全抵消，发动者失去 1 HP。
- 若发动时没有其他存活玩家，则技能不可发动。

#### 实验台起火

- 所有其他存活玩家获得 `FIRE`。
- 这是虚拟角色技能效果，不从手牌发动，不创建 `CardInstance`，不进入弃牌堆。
- 不更新 `tableReference`，也不触发普通实体牌关联门槛。
- 后续由各玩家自己的 `statusWindow` 处理 `FIRE`。
- 若发动时没有其他存活玩家，则技能不可发动。

#### 强放热事故

- 所有其他存活玩家失去 1 HP。
- 该效果不属于 `DAMAGE`，不触发普通响应链、伤害修饰或免疫。
- 同一技能的所有目标结算完成后统一检查胜负。
- 若发动时没有其他存活玩家，则技能不可发动。

### 4. 烧碱大队队长

- `maxHp`：10。

#### 强碱防护

- 被动技能。
- 免疫带有正式碱性伤害标签的 `DAMAGE`。
- 免疫成立后伤害为 0。

#### 碱液回收

- 主动技能，每周期一次。
- 弃置 1 张明确带有实体强碱标签的物质牌。
- 回复 2 HP，不超过 `maxHp`。
- 占用本行动。
- 满 HP 时不可发动。
- 存在 `FIRE` 或 `SO2_LEAK`、因而不能回复时不可发动。
- 发动条件失败时不弃牌、不消耗次数、不占用行动。

#### 强碱专精

- 被动技能。
- 自己使用符合实体强碱标签的牌造成 `DAMAGE` 时，伤害 +1。
- 最终仍受单次 3 点上限。
- 不作用于虚拟 DIY 稀碱。

### 5. 酸王

- `maxHp`：10。

#### 酸性侵蚀

- 被动技能。
- 自己使用符合实体强酸标签的物质牌造成 `DAMAGE` 时，攻击方设定值为 3。
- 高危气体不享受该效果。
- 不作用于虚拟 DIY 稀酸。

#### 耐酸层

- 被动技能。
- 受到正式酸性伤害标签的 `DAMAGE` 时伤害 -1，最低为 1。
- 若另有效果使其完全免疫，免疫优先，最终伤害为 0。

### 6. 化学爱好者

- `maxHp`：8。

#### DIY 实验

- 被动技能。
- 每周期首次成功主动 DIY 若造成 `DAMAGE`，该次伤害 +1。
- 最终仍受单次 3 点上限。
- `usedDIYThisCycle` 仍只由成功主动 DIY 按既有规则维护。
- 不额外创建普通 `CardInstance`。

#### 实验反击

- 响应技能，每周期一次。
- 仅在自己成功完全抵消一次攻击后进入选择。
- 可从以下三个合法选项中选择一个：

**A. 回复 1 HP**

- 不超过 `maxHp`。
- 存在 `FIRE` 或 `SO2_LEAK` 时不可选。
- 满 HP 时不可选。

**B. 金属元素反击**

- 弃置 1 张金属元素牌，对攻击者造成 1 点伤害。
- 不触发普通反应链。
- 当前 68 张真实卡池没有金属元素实体牌，因此当前通常不可选。
- 不得为此新增虚构卡或测试 `CardInstance`。
- 将来只有手中确实存在合法金属元素实体牌时才可选。

**C. 实体酸碱追击**

- 立即打出手中 1 张真实实体酸或碱物质牌；结算后该牌进入弃牌堆。
- 伤害 +1，最终最高为 3。
- 不能被普通反应牌抵消。
- 属于响应技能链，不属于 `mainAction`。
- 不受 `tableReference` 关联门槛限制，不更新 `tableReference`，不改变 `usedDIYThisCycle`。

若三个选项均不可用，不消耗“实验反击”的每周期次数，也不创建空选择窗口。

### 7. 硫酸厂厂长

- `maxHp`：10。

#### 排放尾气

- 主动技能，每周期一次。
- 选择 1 名其他存活玩家，使其获得 `SO2_LEAK`。
- 不造成即时 SO2 `DAMAGE`，不进入普通 `responseWindow`。
- 不更新 `tableReference`，不改变 `usedDIYThisCycle`。
- 占用本行动。
- 没有其他存活目标时不可发动。

#### 硫酸工艺

- 被动技能。
- 自己使用实体 H2SO4 牌造成 `DAMAGE` 时伤害 +1。
- 最终仍受单次 3 点上限。
- 不作用于主动 DIY 产生的虚拟稀 H2SO4。
- 不根据化学式相似或硫酸根来源扩大适用范围。

#### 硫酸盐副产

- 保留正式技能定义，但 Phase 8A、8B 不启用。
- 原规则：自己打出含硫酸根的牌并成功触发反应时摸 1，每实验轮次一次。
- “成功触发反应”的事件定义、触发来源和每轮重置逻辑，延期到通用反应事件系统阶段冻结。
- 延期期间不得通过零散特判实现。
- Debug UI 应标记为“后续阶段启用”或等价说明。

## 七、Phase 8 开发拆分

### Phase 8A：角色数据结构与基础挂载

- 增加 `CharacterId` 与 `CharacterDefinition`。
- 增加 7 个角色静态定义。
- 为 `Player` 挂载 `characterId`。
- 接入角色 `maxHp` 与初始 HP。
- 建立每周期、每实验轮次角色次数状态的最小可扩展结构。
- 建立周期重置基础设施。
- Debug UI 显示角色名称、`maxHp` 和技能说明。
- 不实现具体技能效果。
- 角色不进入主牌堆，普通 `CardInstance` 保持 68。
- 补充 `event_lab_fire.allowedTimings` 为空的数据级保护测试。

### Phase 8B：周期摸牌与低复杂度主动技能

- 实现实验室老师的“备课”“补课”。
- 实现化工厂 CEO 的“资金储备”“紧急调货”。
- 增加必要的安全选牌阶段与持续手牌上限。
- 可在基础标签准备完成后实现“碱液回收”。
- 不实现复杂伤害修饰和多目标响应。

### Phase 8C：复杂技能与通用修饰层

- 实现多目标结算与响应。
- 实现独立“失去体力”效果。
- 实现通用伤害修饰顺序，以及免疫、减伤、设定值和增伤。
- 实现“实验反击”及追击选择窗口。
- 实现“硫酸工艺”等伤害修饰技能。
- 完成实体强酸、实体强碱及正式伤害标签映射。
- 通用反应事件系统完成后再启用“硫酸盐副产”。

## 八、延期内容

- “硫酸盐副产”的成功反应事件定义、触发来源与每实验轮次重置逻辑。
- Phase 8C 之前的复杂伤害修饰、多目标响应和“失去体力”统一结算。
- 响应 DIY。
- 方程式牌、沉淀系统、完整金属反应和完整反应事件系统。
- 当前 68 张卡池之外的真实金属元素实体牌。

## 九、实现禁区

- 不得把 `event_lab_fire` 重新加入 `starterDeck`。
- 不得恢复“实验台起火”万能 `tableReference` 特判。
- 不得增加普通 `CardInstance` 数量。
- 不得为了角色技能添加虚构金属元素牌。
- 不得开放响应 DIY。
- 不得提前实现方程式牌、沉淀系统、完整金属反应或完整反应事件系统。
