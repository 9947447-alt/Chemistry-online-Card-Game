# Phase 8 角色系统规则冻结

本文档是 Phase 8 角色系统的正式冻结规则。它只显式解冻 `docs/MVP0_RULE_FREEZE.md` 中“暂不实现角色、角色体力差异、角色摸牌规则和角色技能”的限制；除本文件明确覆盖的角色相关条款外，MVP 0 的其他冻结规则继续有效。

特别是，7C 关联出牌、68 张普通实体卡池、`tableReference`、主动 DIY、`FIRE` / `SO2_LEAK` 与 `statusWindow`、响应 DIY 关闭等既有规则不得被本阶段隐式改写。`docs/MVP_PLAN.md` 仅记录开发拆分，不得覆盖本文件的冻结规则。

## 一、角色通则

- Phase 8 共冻结 7 个角色。
- 每名玩家挂载 1 个角色。
- 角色牌不进入主牌堆，不创建普通 `CardInstance`。
- 角色技能默认不更新 `tableReference`。
- 角色技能默认不改变 `usedDIYThisCycle`。
- 主动技能只能在行动开始状态处理完成后、正常行动前发动。
- 占用行动的主动技能发动后，本行动不能再普通出牌、执行实体牌效果、主动 DIY，或发动另一个占用行动的主动技能。
- 被动技能不占行动。
- 响应技能只在技能明确指定的窗口发动。
- “失去体力”不是 `DAMAGE`，不触发普通响应、防御、免疫、增减伤或伤害上限。
- 角色的每周期次数在新实验周期开始时重置。
- 角色的每实验轮次次数在新实验轮次开始时重置。
- 角色技能不得重新引入 `event_lab_fire` 普通实体牌。
- 角色系统不得改变普通实体卡池 68 张的冻结数量。

## 二、回复规则

- 玩家存在 `FIRE` 或 `SO2_LEAK` 时，不能通过普通卡牌或角色技能回复体力，除非未来效果明确写出例外。
- 回复技能发动前必须先检查玩家能否回复。
- 若完全不能回复，对应回复选项或主动技能不可发动：不弃牌、不消耗技能次数、不占用行动，也不产生其他副作用。
- 回复不得超过 `maxHp`。

## 三、持续手牌上限

- 化工厂 CEO 的手牌上限 14 在所有时点生效，不只作用于周期开始摸牌。
- 任何摸牌效果达到 14 张后立即停止继续摸牌。
- 不设计“超过后弃牌”；正常结算不得使 CEO 手牌超过 14。
- 其他角色暂不设置持续手牌上限；其周期开始摸牌数量仍按各自角色规则执行。

## 四、强酸、强碱与虚拟 DIY 边界

`strong-acid` 和 `strong-alkali` 是角色规则专用的实体物质标签，只能由实体 `CardDefinition.tags` 明确声明。它们不能替代现有 `acid` / `base`：`acid` / `base` 继续用于既有攻击类型、响应、关联及其他已经实现的规则。一张实体强酸牌必须同时具有 `acid` 和 `strong-acid`；一张实体强碱牌必须同时具有 `base` 和 `strong-alkali`。

正式映射如下：

| 实体 `CardDefinition.id` | 保留标签 | 新增角色标签 |
| --- | --- | --- |
| `substance_hcl_dilute` | `acid` | `strong-acid` |
| `substance_h2so4_dilute` | `acid` | `strong-acid` |
| `substance_naoh_dilute` | `base` | `strong-alkali` |
| `substance_koh_dilute` | `base` | `strong-alkali` |
| `substance_caoh2_limewater` | `base` | `strong-alkali` |

除表中五个实体物质定义外，当前任何其他卡牌均不得获得 `strong-acid` 或 `strong-alkali`。特别是：

- Ca(OH)2 / 石灰水正式纳入实体 `strong-alkali` 映射。
- H+、OH- 及其他全部离子牌、全部元素牌均排除。
- H2O、O2、CO2、SO2、Na2CO3、`event_lab_fire` 均排除。
- 状态与角色定义不使用这两个卡牌标签。
- 主动 DIY 构建的虚拟稀 HCl、稀 H2SO4、稀 NaOH、稀 KOH、稀 Ca(OH)2 / 石灰水全部排除；它们仍只有各自普通酸性或碱性伤害属性，不读取或复用同名实体 `CardDefinition` 的标签对象。
- 引擎和角色效果不得根据卡牌中文名、化学式字符串、card ID 命名规律、`ionsProvided` 或现实化学知识临时推断这两个标签。

Phase 8C-0A 只完成上述标签数据与规则冻结；伤害上下文、伤害修饰及相关角色技能尚未接入。

### Phase 8C-0B：统一伤害上下文

所有当前普通 `DAMAGE` 统一携带一个结构化 `DamageContext`，由以下字段组成：

- `targetPlayerId`：当前伤害目标。
- `baseAmount`：进入未来修饰管线前的非负基础伤害值。
- `source`：强类型 `DamageSource` 判别联合。
- `tags`：去重且顺序稳定的 `readonly DamageTag[]`。
- `responsePolicy`：明确的响应策略。

`DamageSource` 当前冻结为四类：

- `card`：保存实际出牌者 `sourcePlayerId`、真实 `cardInstanceId` 和稳定的 `cardDefinitionId`。
- `diy`：保存发动者 `sourcePlayerId` 和 `recipeId`；不得包含或伪造结果 `CardInstance`。
- `status`：保存具体 `statusId` 与状态实例 ID；当前伤害上下文的 `sourcePlayerId` 固定为 `null`，不得把状态持有者或 `PlayerStatus` 中尚未正式冻结的来源字段猜作攻击者。
- `character-skill`：预留 `sourcePlayerId` 与 `skillId` 的强类型分支；Phase 8C-0B 不产生新的角色技能伤害。

`DamageTag` 与当前生成规则如下：

- 实体酸碱攻击只从明确的 `CardDefinition.tags` 读取 `acid` / `base` / `strong-acid` / `strong-alkali`。
- 虚拟 DIY 只从 recipe 已冻结的伤害种类生成 `acid` 或 `base`，不得获得实体强酸、强碱标签。
- `FIRE` 状态伤害使用 `status` + `fire`；`SO2_LEAK` 状态伤害使用 `status` + `so2`。
- 不根据名称、化学式、card ID、离子来源或现实知识推断伤害标签。

`ResponsePolicy` 当前包括 `acid-base`、`alkali-absorption` 和 `none`。实体与虚拟酸碱攻击使用 `acid-base`；行动开始状态伤害使用 `none`；Phase 8C-3 起，书记“尾气泄漏”的即时 SO2 普通伤害使用 `alkali-absorption`，并通过多目标连续响应入口逐名结算。`SO2_LEAK` 状态伤害仍不使用该响应策略。

Phase 8C-0B 完成时只进行了行为等价的数据迁移；Phase 8C-1 已在该上下文之上接入统一普通 `DAMAGE` 管线。未来若需要把状态施加者作为伤害来源，必须另行冻结状态来源追踪规则。

## 五、普通 DAMAGE 修饰顺序

普通 `DAMAGE` 按以下固定顺序结算：

1. 确定基础伤害。
2. 应用攻击方“伤害视为 X”等设定值效果。
3. 应用攻击方加法增伤。
4. 检查防御方免疫；若免疫成立，最终伤害直接为 0，并跳过最低伤害规则。
5. 应用防御方减伤。
6. 应用技能明确写出的最低伤害值。
7. 应用普通单次伤害最高 3 点上限。
8. 扣除 HP，检查淘汰与 `gameOver`。

补充边界：

- “免疫”优先于“最低为 1”。
- 没有最低值文字时，减伤可以使伤害降为 0。
- 普通伤害不得低于 0。
- “失去体力”完全绕过上述 `DAMAGE` 修饰顺序。
- Phase 8A 不实现通用伤害修饰层；该工作属于 Phase 8C。

### Phase 8C-1：通用结算基础设施

Phase 8C-1 已完成以下基础设施：

- 普通 `DAMAGE` 由集中纯函数按上述八步顺序解析；结果包含强类型、只读、顺序固定的阶段 trace，`applyDamage` 只按最终实际伤害扣除 HP。
- 所有现有实体攻击、虚拟 DIY 与 `FIRE` / `SO2_LEAK` 状态伤害均进入同一管线；没有修饰器时仍分别造成原有 1 点或 2 点伤害。
- 修饰输入按设定值、增伤、免疫、减伤、最低值五个阶段分栏，每个阶段当前至多接受一个已经解析的修饰及其强类型来源。多个同阶段修饰器的收集、优先级或叠加方式尚未冻结，本阶段不作推断。
- 本阶段没有接入任何具体角色修饰器；酸性侵蚀、强碱防护、强碱专精、耐酸层、DIY 实验、硫酸工艺等仍未生效。
- 独立批量“失去体力”基础设施已完成。它不创建 `DamageContext`，不读取 `DamageTag`，不进入普通伤害管线或响应窗口，也不受最低值和 3 点上限影响。
- 批量失去体力先原子校验全部输入，再按玩家固定顺序一次性更新全部 HP，之后统一标记淘汰并只进行一次胜负判断。重复目标、未知或已淘汰目标、负数、`NaN`、`Infinity` 均零副作用拒绝；全 0 批次为安全无操作。
- 同一批次所有玩家同时归零时，沿用既有 MVP 0 规则判为平局。

Phase 8C-1 不新增玩家 action，不接入“强放热事故”，不实现多目标响应、实验反击、书记技能或其他具体角色技能。

### Phase 8C-2：单目标普通 DAMAGE 角色被动

Phase 8C-2 已在既有单目标普通 `DAMAGE` 管线上接入以下六个冻结被动：

- 烧碱大队队长“强碱防护”：目标受到带 `base` 标签的 `DAMAGE` 时提供免疫。
- 烧碱大队队长“强碱专精”：来源为真实实体牌、且上下文与卡牌定义均明确带 `strong-alkali` 时提供伤害 +1。
- 酸王“酸性侵蚀”：来源为真实实体牌、上下文与卡牌定义均明确带 `strong-acid`、且卡牌定义不带 `harmful-gas` 时，在设定值阶段将伤害设为 3。
- 酸王“耐酸层”：目标受到带 `acid` 标签的 `DAMAGE` 时，在减伤阶段 -1，并在最低值阶段设最低 1；免疫仍优先。
- 化学爱好者“DIY 实验”：当前合法伤害型主动 DIY 进入响应窗口时，复用 `usedDIYThisCycle` 的每周期限一次语义，在增伤阶段 +1；不增加第二套 DIY 次数状态。
- 硫酸厂厂长“硫酸工艺”：来源为真实实体 `substance_h2so4_dilute` 时，在增伤阶段 +1。

所有角色判断集中在生产修饰器收集入口；`applyDamage` 仍是唯一扣除普通伤害 HP 的入口，八步顺序、3 点上限、`responsePolicy`、响应成功完全抵消及放弃响应后恢复原始 `DamageContext` 的语义不变。虚拟 DIY 只保留普通 `acid` / `base` 伤害标签，不获得实体强酸/强碱技能；状态伤害的 `sourcePlayerId` 仍为 `null`，不推断状态施加者。

本阶段没有实现碱液回收、书记三个主动技能、排放尾气、实验反击、多目标响应、实验反击选择窗口、硫酸盐副产或通用反应事件系统，也没有接入任何具体失去体力技能入口。

### Phase 8C-3：剩余主动技能与连续响应

Phase 8C-3 已完成以下冻结能力：

- 烧碱大队队长“碱液回收”：每周期一次，原子校验并弃置本人手牌区内明确带 `strong-alkali` 的实体物质牌，复用统一回复阻止规则回复至多 2 HP。
- 硫酸厂厂长“排放尾气”：每周期一次，向一名其他存活玩家施加 `SO2_LEAK`，不造成即时伤害或打开响应窗口。
- 手残党党委书记“尾气泄漏”“实验台起火”“强放热事故”：三项主动技能共享 `clumsy_party_secretary_shared_active` 每周期次数。
- “尾气泄漏”使用 `character-skill` 来源、`so2` 标签和 `alkali-absorption` 响应策略，按稳定目标快照逐名处理；响应牌只读取真实定义上的 `alkaline-absorb` 及既有合法时机。
- 连续响应状态保存来源玩家、来源技能、完整目标快照、当前响应者、剩余目标和已完成结果。当前双人游戏也使用该通用队列，不设置单目标特判。
- 所有目标均成功吸收时，书记通过独立失去体力入口失去 1 HP；只要任一目标承受伤害则不失去体力。统一胜负判断只在全部目标完成后执行。
- “实验台起火”只产生虚拟角色技能状态效果，不创建或使用 `event_lab_fire` CardInstance；“强放热事故”只调用批量失去体力入口，不创建 `DamageContext`。

本阶段没有实现实验反击及其选择窗口、硫酸盐副产、通用反应事件系统、响应 DIY、方程式牌、沉淀或完整金属系统。

## 六、角色冻结规则

### 1. 实验室老师

- `maxHp`：10。

#### 备课

- 周期开始触发。
- 摸 20 张，选择 10 张作为手牌，其余弃置。
- 不占行动。
- 必须使用安全、显式的选牌阶段，不能由 UI 直接修改状态。
- 若牌堆不足，沿用现有牌堆重洗规则。

#### 补课

- 主动技能，每周期一次。
- 手牌不超过 4 张时才能发动。
- 摸 4 张。
- 占用本行动。
- 不更新 `tableReference`。
- 不改变 `usedDIYThisCycle`。

### 2. 化工厂 CEO

- `maxHp`：10。

#### 资金储备

- 周期开始摸 14 张。
- 手牌上限始终为 14。
- 不需要选牌阶段。

#### 紧急调货

- 主动技能，每周期一次。
- 手牌不超过 4 张时才能发动。
- 摸 3 张，但不能超过 14 张上限。
- 占用本行动。
- 不更新 `tableReference`。
- 不改变 `usedDIYThisCycle`。

### 3. 手残党党委书记

- `maxHp`：10。
- 每周期最多发动以下三个主动技能中的任意一个，三个技能共享同一个每周期次数。

#### 尾气泄漏

- 所有其他存活玩家分别受到即时 2 点 SO2 `DAMAGE`。
- 每名目标可使用合法碱性吸收响应，多目标分别结算。
- 若所有合法目标最终都完全抵消，发动者失去 1 HP。
- 若发动时没有其他存活玩家，则技能不可发动。

#### 实验台起火

- 所有其他存活玩家获得 `FIRE`。
- 这是虚拟角色技能效果，不从手牌发动，不创建 `CardInstance`，不进入弃牌堆。
- 不更新 `tableReference`，也不触发普通实体牌关联门槛。
- 后续由各玩家自己的 `statusWindow` 处理 `FIRE`。
- 若发动时没有其他存活玩家，则技能不可发动。

#### 强放热事故

- 所有其他存活玩家失去 1 HP。
- 该效果不属于 `DAMAGE`，不触发普通响应链、伤害修饰或免疫。
- 同一技能的所有目标结算完成后统一检查胜负。
- 若发动时没有其他存活玩家，则技能不可发动。

### 4. 烧碱大队队长

- `maxHp`：10。

#### 强碱防护

- 被动技能。
- 免疫带有正式碱性伤害标签的 `DAMAGE`。
- 免疫成立后伤害为 0。

#### 碱液回收

- 主动技能，每周期一次。
- 弃置 1 张明确带有实体强碱标签的物质牌。
- 回复 2 HP，不超过 `maxHp`。
- 占用本行动。
- 满 HP 时不可发动。
- 存在 `FIRE` 或 `SO2_LEAK`、因而不能回复时不可发动。
- 发动条件失败时不弃牌、不消耗次数、不占用行动。

#### 强碱专精

- 被动技能。
- 自己使用符合实体强碱标签的牌造成 `DAMAGE` 时，伤害 +1。
- 最终仍受单次 3 点上限。
- 不作用于虚拟 DIY 稀碱。

### 5. 酸王

- `maxHp`：10。

#### 酸性侵蚀

- 被动技能。
- 自己使用符合实体强酸标签的物质牌造成 `DAMAGE` 时，攻击方设定值为 3。
- 高危气体不享受该效果。
- 不作用于虚拟 DIY 稀酸。

#### 耐酸层

- 被动技能。
- 受到正式酸性伤害标签的 `DAMAGE` 时伤害 -1，最低为 1。
- 若另有效果使其完全免疫，免疫优先，最终伤害为 0。

### 6. 化学爱好者

- `maxHp`：8。

#### DIY 实验

- 被动技能。
- 每周期首次成功主动 DIY 若造成 `DAMAGE`，该次伤害 +1。
- 最终仍受单次 3 点上限。
- `usedDIYThisCycle` 仍只由成功主动 DIY 按既有规则维护。
- 不额外创建普通 `CardInstance`。

#### 实验反击

- 响应技能，每周期一次。
- 仅在自己成功完全抵消一次攻击后进入选择。
- 可从以下三个合法选项中选择一个：

**A. 回复 1 HP**

- 不超过 `maxHp`。
- 存在 `FIRE` 或 `SO2_LEAK` 时不可选。
- 满 HP 时不可选。

**B. 金属元素反击**

- 弃置 1 张金属元素牌，对攻击者造成 1 点伤害。
- 不触发普通反应链。
- 当前 68 张真实卡池没有金属元素实体牌，因此当前通常不可选。
- 不得为此新增虚构卡或测试 `CardInstance`。
- 将来只有手中确实存在合法金属元素实体牌时才可选。

**C. 实体酸碱追击**

- 立即打出手中 1 张真实实体酸或碱物质牌；结算后该牌进入弃牌堆。
- 伤害 +1，最终最高为 3。
- 不能被普通反应牌抵消。
- 属于响应技能链，不属于 `mainAction`。
- 不受 `tableReference` 关联门槛限制，不更新 `tableReference`，不改变 `usedDIYThisCycle`。

若三个选项均不可用，不消耗“实验反击”的每周期次数，也不创建空选择窗口。

### 7. 硫酸厂厂长

- `maxHp`：10。

#### 排放尾气

- 主动技能，每周期一次。
- 选择 1 名其他存活玩家，使其获得 `SO2_LEAK`。
- 不造成即时 SO2 `DAMAGE`，不进入普通 `responseWindow`。
- 不更新 `tableReference`，不改变 `usedDIYThisCycle`。
- 占用本行动。
- 没有其他存活目标时不可发动。

#### 硫酸工艺

- 被动技能。
- 自己使用实体 H2SO4 牌造成 `DAMAGE` 时伤害 +1。
