# Chemistry-online-Card-Game

化学在线卡牌游戏。

## MVP 0 项目命令

```bash
pnpm install
pnpm run dev
pnpm run build
pnpm exec vitest run
```

本地开发服务启动后，按终端输出的 Vite 地址在浏览器打开即可。

## 当前阶段

当前仅初始化 React + TypeScript + Vite + Vitest 项目骨架。MVP 0 规则以 `docs/MVP_PLAN.md` 为准，规则引擎 Alpha 尚未实现。
